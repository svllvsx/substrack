<h1 align="center">SubsTrack</h1>

SubsTrack — учёт подписок, напоминания о продлении, календарь платежей и обзор расходов для Android и веба.

Это публичная витрина проекта. Публичные сборки, скриншоты и инструкции находятся в [оригинальном репозитории](https://github.com/svllvsxprod/substrack-releases). Полная копия исходного README сохранена [здесь](README.md).

**Темы:** `subscriptions`, `budgeting`, `calendar`, `mobile-app`, `releases`

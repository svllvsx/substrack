<h1 align="center">SubsTrack Releases</h1>

Публичные сборки менеджера подписок с регулярными платежами, календарём продлений и обзором расходов.

Это публичная витрина проекта. Исходники, актуальные сборки и инструкции находятся в [оригинальном репозитории](https://github.com/svllvsxprod/substrack-releases). Полная копия исходного README сохранена [здесь](README.md).

**Темы:** `subscriptions`, `budgeting`, `calendar`, `mobile-app`, `releases`
